# Neurofuzzy Semantic Similarity Measurement

A clean, reproducible Python implementation of a **fuzzy-inference** approach to
**semantic similarity measurement**, with a unified benchmark harness, reference
baselines, bootstrap confidence intervals, paired significance tests, and
publication-quality figures.

This is the companion code for:

> Martinez-Gil, J., Mokadem, R., Küng, J., & Hameurlain, A. (2023).
> *Neurofuzzy semantic similarity measurement.* Data & Knowledge Engineering,
> 145, 102155. <https://doi.org/10.1016/j.datak.2023.102155>

## Why use it?

- **Standardized benchmark** you can compare any method against.
- **Reproducible**: every number is regenerated from data with a recorded manifest.
- **Fast & light**: a pure-NumPy, fully vectorized fuzzy controller.
- **Teachable**: examples, a notebook, and clear module boundaries.

Start with the [Quickstart](quickstart.md), then read the
