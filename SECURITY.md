# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | Yes       |
| < 1.1   | No        |

## Reporting a vulnerability

This is a research codebase with no network-facing components, but we take
correctness and supply-chain concerns seriously.

If you discover a security issue (for example, a dependency vulnerability or a
problem that could lead to arbitrary code execution when processing untrusted
data files), please report it privately:

1. Preferred: open a [GitHub Security Advisory](https://github.com/jorge-martinez-gil/dke2023/security/advisories/new).
2. Alternatively, email the maintainer at jorgemarcc@gmail.com with the subject
   line `SECURITY: dke2023`.

Please do **not** open a public issue for security reports. We aim to acknowledge
reports within 7 days and to provide a remediation timeline after triage.
