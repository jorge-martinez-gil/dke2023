# Examples

Runnable, self-contained examples. Execute them from the repository root.

| Example | What it shows |
|---|---|
| [`minimal_example.py`](minimal_example.py) | Load data, fit the model, predict, and evaluate. |
| [`custom_dataset.py`](custom_dataset.py) | Evaluate on your own dataset file. |
| [`add_baseline.py`](add_baseline.py) | Implement and benchmark a custom baseline method. |

```bash
python examples/minimal_example.py
python examples/custom_dataset.py datasets/geresid.txt
python examples/add_baseline.py
```
